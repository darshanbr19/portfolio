Medical Imaging · Deep Learning

Pneumonia Detection from Chest X-Ray Images

A DenseNet121 + CBAM attention model for chest X-ray pneumonia classification. Trained with patient-grouped Stratified 5-Fold Cross-Validation, Binary Focal Loss, and label smoothing to eliminate data leakage and handle class imbalance. Inference uses a 5-view Test-Time Augmentation ensemble (25 predictions per image) with the optimal decision threshold selected via Youden's J statistic (0.7984).

Deployed as a Streamlit app with Grad-CAM++ heatmaps so radiologists can verify model attention on pathologically relevant lung regions before trusting a prediction.
